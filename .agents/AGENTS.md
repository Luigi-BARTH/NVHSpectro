# Agent Behavioral Rules & Procedures for NVH Spectro

## Documentation Maintenance Procedure
Whenever modifying code (architecture, DSP algorithms, UI features, or settings) in `NVHSpectro`, you **MUST** update the documentation file:
`doc/ARCHITECTURE_AND_DSP_METHODS.md`
before running a `git commit`.

Ensure that:
1. All changes to algorithms, formulas, parameters, UI layouts, or metadata are documented.
2. The version number and feature matrix remain synchronized with the code.
